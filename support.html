Frequently Asked Questions

How do I get API keys?

Free users need to provide their own API keys:

  • Google Gemini: Visit ai.google.dev, sign in, and create an API key
  • OpenAI: Go to platform.openai.com, create an account, and generate an API key

Enter your keys in Profile → API Keys.

Why isn't my podcast generating?

Check the following:

  • Ensure you've added valid API keys (free users)
  • Verify you haven't reached your daily limit
  • Make sure your input text is at least 100 words
  • Check your internet connection
  • Verify your API key is active and has credits

How do I reset my trial limits?

Trial limits reset automatically every 24 hours. You can check when your limits reset in Profile → Trial Usage.

Upgrade to Mai Pro for generous daily allowances.

Is my data private?

Yes! All your study data is stored locally on your device. We never send your data to our servers. API keys are stored securely in iOS Keychain.

Can I export my data?

Data export is coming in a future update. For now, you can manually copy content from generated podcasts, flashcards, and study guides.

What's the difference between free and Pro?

Free Tier:
• Strictly limited (e.g. 5 chats/day)
• Requires your own API keys for unlimited use

Mai Pro:
• Generous daily limits (e.g. 20 chats, 3 podcasts)
• No API keys needed
• Priority support
• Supports the app's development
